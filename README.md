## 淨水器公式（簡化）

```
每晚去除量 = 31.25 ml × 體積加成 × (100% + 髒污加成 + 性能)
```

- 體積加成：每 1000 ml +12%，10000 ml 封頂（×1 ~ ×2.2）
- 髒污加成：初始純度 98% 以上無加成，越髒越高，最多 +1900%
- 性能：模組性能（Performance）總和
- 純度上限（依模組質量）：99.01 / 99.16 / 99.36 / 99.66 / 99.81 / 99.91 / 100%

數值依社群逆向模型（build 26337366）簡化，忽略整數截斷，僅供參考。
