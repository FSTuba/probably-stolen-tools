淨水器試算器

《Probably Stolen》淨水器一晚能去除多少雜質、最後能到多純。

怎麼算

每晚去除量 = 31.25 ml × 體積加成 × (100% + 髒污加成 + 性能)

  • 體積加成：容器每 1000 ml +12%，10000 ml 封頂（×1 ~ ×2.2）。
  • 髒污加成：水越髒、加成越多；同一段內依純度線性變化：
    初始純度每少 1% 純度段尾累計
    98% 以上無加成+0%
    98% → 94%+25%+100%
    94% → 88.5%+54.5%+400%
    88.5% → 80%+58.8%+900%
    80% → 62.5%+28.6%+1400%
    62.5% → 37.5%+20%+1900%
    37.5% 以下封頂+1900%
  • 性能：裝上模組的性能總和，直接加進括號裡（性能 100% = 多一份基礎去除量）。
  • 質量上限：由模組質量決定，結果純度不會超過上限，超出的去除量會浪費掉。
